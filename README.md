# Minecraft Mods Issue Tracker

This repository is the central place to report **bugs** and suggest **features/improvements** for my Minecraft mods.

## How to Report a Bug

1. Check existing issues to see if it's already reported.
2. Click **New issue** and choose the **Bug Report** template.
3. Fill out as much detail as possible (Minecraft version, mod version, logs, steps to reproduce, etc.).

## How to Suggest a Feature

1. Click **New issue** and choose the **Feature Request** template.
2. Describe the idea clearly.
